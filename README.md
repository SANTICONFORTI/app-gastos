# Puly

Web app (PWA) para controlar gastos personales y compartidos, hecha para Argentina: cuotas, eventos sin registro, dólar blue y tarjeta, y Wrapped para compartir.

## Cómo correrla en tu compu

1. Instalá [Node.js](https://nodejs.org) (versión 20 o más nueva).
2. Copiá `.env.example` como `.env` y completá los valores de Supabase.
3. En la carpeta del proyecto:

```bash
npm install
npm run dev
```

4. Abrí http://localhost:5173 en el navegador.

## Stack

React + Vite, Framer Motion, Lucide, Supabase. Deploy automático en Vercel con cada push a `main`.

El brief completo del proyecto está en [CLAUDE.md](CLAUDE.md).
